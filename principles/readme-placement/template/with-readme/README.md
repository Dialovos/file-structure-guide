# with-readme/

A small example showing what a junction README looks like.

## What's here

- `file1.md` — a placeholder document that this directory exists to hold.

## How it's organised

One file per concept, named in kebab-case. New documents go here as siblings; if
the directory grows past ~10 entries, consider splitting by sub-topic.

## Where to next

- Parent: see `template/README.md` for the bigger picture.
- Sibling: `../without-readme/` shows when a README is *not* needed.

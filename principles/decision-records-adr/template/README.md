# decision-records-adr — template

A `docs/adr/` directory with an index, a first record, and a template.

## What to rename

- `0001-record-architecture-decisions.md` date and names to your project

## What to fill

- `docs/adr/README.md` — add a row per new record
- `docs/adr/template.md` — copy for each new decision

## What to delete

- The example records once you have real ones

## First run

```bash
cp docs/adr/template.md docs/adr/0002-your-decision.md
```

## Pair this with

- `../GUIDE.md` — the reasoning
- `../../indexes-and-mocs/` — keeping the list navigable

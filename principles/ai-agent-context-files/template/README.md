# ai-agent-context-files — template

A shared `AGENTS.md` with thin tool-specific pointers, ready to copy into a repository.

## What to rename

- Placeholders in `AGENTS.md` (commands, layout) to match your project

## What to fill

- `AGENTS.md` — the real commands, conventions, and boundaries
- Delete pointer files for tools you don't use

## What to delete

- Pointer files for tools nobody on the team uses
- Any rule you can't make concrete and checkable

## First run

```bash
# verify every command listed in AGENTS.md runs from a clean clone
```

- `../GUIDE.md` — the reasoning
- `../../readme-placement/` — where human documentation goes

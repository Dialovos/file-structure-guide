# lowercase-feature

This file demonstrates a non-canonical document that follows the
capitalization policy: lowercase, kebab-case, no SHOUTING.

In a real project this might be `docs/feature-flags.md`,
`docs/release-process.md`, or any other topical doc. None of those are part
of the canonical UPPERCASE set, so they live lowercase.

## Why this filename matters

If this file were named `LOWERCASE-FEATURE.md`, it would visually compete
with `README.md` and `CONTRIBUTING.md` for attention. Readers learn to
scan UPPERCASE filenames first; reserving the case for the canonical set
keeps that signal sharp.

If it were named `Lowercase-Feature.md` (Title Case), it would look like a
typo of either canonical or lowercase. The two-case rule (UPPERCASE
canonical or lowercase non-canonical, nothing in between) avoids that
ambiguity entirely.

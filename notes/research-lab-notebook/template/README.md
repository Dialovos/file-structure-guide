# research-lab-notebook — template

A lab-notebook skeleton with a dated log, numbered experiment folders that start with a hypothesis, and a questions list.

## What to rename

- Project name in `README.md`

## What to fill

- `questions.md` — your real open questions
- `experiments/0001-example/README.md` — copy `experiments/_template/` for each new experiment

## What to delete

- `experiments/0001-example/` once you have real experiments

## First run

```bash
cp -r experiments/_template experiments/0002-your-slug
```

## Pair this with

- `../GUIDE.md` — the reasoning
- `../../../code/ml-experiment-project/` — runs and configs

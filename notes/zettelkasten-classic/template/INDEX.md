# Zettelkasten index

Entry points into this slip box. Maps of Content (MOCs) themselves live in `permanent/`; this file just lists the most useful ones.

## Active MOCs

- [[attention-and-deep-work-MOC]] — claims about attention as a scarce resource and what makes deep work possible.
- [[learning-and-memory-MOC]] — notes on spaced repetition, retrieval practice, and elaborative encoding.

> Replace the lines above with your own MOCs as your `permanent/` folder grows. A useful MOC links 5-7 permanent notes that form an argumentative thread.

## Folder roles

- `inbox/` — raw capture. Process weekly into the other two folders or delete.
- `permanent/` — atomic, evergreen notes. Each one represents *one* claim, expressed in your own words, densely linked to other permanent notes.
- `literature/` — source-extraction notes. One per book / paper / talk. Cite keys match `references.bib`.
- `references.bib` — BibTeX. Every literature note has a BibTeX entry; the cite key matches the filename.

## Daily routine

1. Capture freely into `inbox/` throughout the day.
2. Once a day (or once a week), pull each inbox note and decide:
   - throw it away, or
   - rewrite it as a new atomic note in `permanent/` with timestamp-prefixed ID, or
   - extract it into an existing literature note if it was a quote.
3. Add at least two links from any new permanent note to existing ones.
4. When five or more notes form a thread, write a MOC and link it from this index.

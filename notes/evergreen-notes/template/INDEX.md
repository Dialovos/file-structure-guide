## Conventions

- All evergreen notes live flat in this folder.
- Filenames are *claims*, lowercase-hyphenated, 4-9 words.
- Each note links to at least 2-3 others; isolation means it isn't ready.
- This index is itself an evergreen note — refine it over time.

# course-notes-structure — template

A per-course folder skeleton and README template. Copy it once per course per term.

## What to rename

- `cs-101` to the real course code
- The term folder name to the current term

## What to fill

- `README.md` (the course's own, copied from `course-readme.md`) — instructor, schedule, weights, deadlines, links

## What to delete

- Subfolders the course doesn't use (for example `project/`)

## First run

```bash
cp -r template school/2026-fall/cs-101
```

## Pair this with

- `../GUIDE.md` — the reasoning
- `../../../principles/iso-date-formats/` — dated filenames

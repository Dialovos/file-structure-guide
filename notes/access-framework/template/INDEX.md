# Vault INDEX (ACCESS framework)

Top-level Map of Content for this vault. Six-folder ACCESS layout — Action / Categories / Concepts / Entries / Search / Sources.

## Six buckets

| Folder | Purpose | Cadence |
| --- | --- | --- |
| `1-action/` | Active projects and to-dos | Days to weeks |
| `2-categories/` | Durable areas of life | Years |
| `3-concepts/` | Evergreen claims (your ideas) | Refined over years |
| `4-entries/` | Daily, weekly, journal | Append daily |
| `5-search/` | Saved queries, indexes | Curated as the vault grows |
| `6-sources/` | Literature notes (others' ideas) | Append as you read |

## Entry points

- **Today:** open `4-entries/YYYY-MM-DD.md` for the daily note.
- **Active work:** see `1-action/` — one folder or file per project.
- **Long-running areas:** see `2-categories/` — life-MOCs by domain (health, career, finance, ...).
- **Refined thinking:** see `3-concepts/` — claim-titled atomic notes.
- **What you're reading:** see `6-sources/` — literature notes by source.
- **How to find things:** see `5-search/` — saved searches and Dataview indexes.

## Discipline

- Concepts cite sources. Sources do not pretend to be concepts.
- Action is transient; Categories are durable. Don't conflate them.
- When in doubt, put the note where you'd look for it in six months.

# Atomic notes should be embeddable

The test for whether a note is atomic: can you quote it *in full*
inside another note without (a) bringing along irrelevant material
or (b) leaving out load-bearing context?

If quoting it pulls in three other ideas you didn't want, the note
is too big. If quoting it leaves the reader needing the surrounding
prose to make sense, the note is too small.

This is a more useful test than word count. A 1,500-word atomic note
on a single mechanism passes the embeddability test; a 200-word note
that bundles "three thoughts on productivity" fails it.

The corollary: the title of an atomic note is the question its body
answers. If you can't write a single-sentence title, you don't have
one idea.

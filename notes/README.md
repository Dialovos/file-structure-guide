# Notes & knowledge layouts

23 systems for organizing notes, journals, and knowledge bases. They cluster into a handful of philosophies — pick the one whose "When to use" reflects how you actually work, not how you wish you worked.

## Project- and area-driven

- [`para/`](para/) — Projects / Areas / Resources / Archive (Tiago Forte)
- [`gtd-digital/`](gtd-digital/) — Getting Things Done in flat markdown
- [`second-brain-code/`](second-brain-code/) — Capture / Organize / Distill / Express

## ID-numbered filing

- [`johnny-decimal/`](johnny-decimal/) — numeric IDs, ≤100 categories
- [`folgezettel/`](folgezettel/) — Luhmann-style branching IDs (`1.1a`, `1.1a1`)

## Atomic interlinked

- [`zettelkasten-classic/`](zettelkasten-classic/) — inbox / permanent / literature
- [`atomic-notes/`](atomic-notes/) — one-idea-per-note pattern (philosophy)
- [`evergreen-notes/`](evergreen-notes/) — Andy Matuschak's evergreen rules
- [`lyt-linking-your-thinking/`](lyt-linking-your-thinking/) — Nick Milo's MOC-driven approach
- [`maps-of-content/`](maps-of-content/) — MOC pattern in isolation

## Date-driven

- [`daily-weekly-notes/`](daily-weekly-notes/) — one note per day/week
- [`bullet-journal-digital/`](bullet-journal-digital/) — Ryder Carroll's BuJo digitized
- [`roam-daily-pages/`](roam-daily-pages/) — daily-page-as-canonical-entry

## Reference frameworks

## How to pick

If you already use a tool (Obsidian, Logseq, Roam), start with the tool-specific guide; layer a philosophy (PARA, Zettelkasten, LYT) on top. Otherwise [`CHOOSE.md`](../CHOOSE.md) walks you through it.

# Index

Carroll's "Index" page — a hand-curated table of contents over your
collections. Daily and monthly logs are *not* indexed (they're
chronological; navigate by date). Only collections appear here.

When you start a new collection, add an entry to this list.

## Collections

- [Books to read](collections/example.md) — reading queue + finished list
- [Habit tracker 2026](collections/habit-tracker-2026.md) — daily habit grid
- [Trip planning](collections/trip-planning.md) — destinations + notes
- [Someday / maybe](collections/someday.md) — aspirations (not the Future Log)
- [Project: vault redesign](collections/project-vault-redesign.md) — design doc + open questions

## Modules (top-level)

- [Future Log](future-log.md) — fixed dates 3-12 months out
- Monthly logs — `monthly/YYYY-MM.md`
- Daily logs — `daily/YYYY-MM-DD.md`

## Notes

- This Index is hand-maintained. Don't auto-generate it; the act of
  adding to the Index is part of the BuJo discipline.
- If a collection hasn't been touched in 6 months, archive or delete it.

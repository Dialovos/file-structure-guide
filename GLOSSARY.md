# Glossary

Terms used across guidelines. Each links to the canonical guideline that defines or uses it.

## A

- **atomic note** — a note small enough to capture exactly one idea. Used in Zettelkasten-style systems. See [`notes/atomic-notes/`](notes/atomic-notes/).

## D

- **dotfile** — a file or directory whose name begins with `.`, hidden by default in Unix listings. See [`principles/hidden-files-policy/`](principles/hidden-files-policy/).

## E

- **evergreen note** — a note refined over time toward stable, reusable knowledge. See [`notes/evergreen-notes/`](notes/evergreen-notes/).

## F

- **FHS** — Filesystem Hierarchy Standard, the Linux conventional layout for `/usr`, `/var`, `/etc`. See [`files/unix-fhs/`](files/unix-fhs/).
- **flat layout** — a Python project layout where the import package sits at the repo root rather than under `src/`. See [`code/python-flat-layout/`](code/python-flat-layout/).
- **Folgezettel** — Luhmann-style alphanumeric IDs encoding parent/child branching in flat-file Zettelkasten. See [`notes/folgezettel/`](notes/folgezettel/).

## J

- **Johnny.Decimal** — a numeric ID system organizing notes/files into ≤100 categories. See [`notes/johnny-decimal/`](notes/johnny-decimal/).

## M

- **Maildir** — Bernstein's per-message-file mail storage layout (`new/`, `cur/`, `tmp/`). See [`files/maildir/`](files/maildir/).
- **MOC** (Map of Content) — an index note linking related atomic notes. See [`notes/maps-of-content/`](notes/maps-of-content/).
- **monorepo** — a single repository containing multiple independently buildable projects. See [`code/turborepo-monorepo/`](code/turborepo-monorepo/) and [`code/nx-monorepo/`](code/nx-monorepo/).

## P

- **PARA** — Projects/Areas/Resources/Archive, Tiago Forte's note-organization framework. See [`notes/para/`](notes/para/).

## S

- **scaffold** — a starter directory tree, copyable as a project's initial layout. Every `template/` in this repo is a scaffold.
- **src layout** — a Python project layout where source lives under `src/<package>/`, isolating it from the repo root. See [`code/python-src-layout/`](code/python-src-layout/).

## X

- **XDG** — XDG Base Directory Specification, freedesktop.org's standard for `$XDG_CONFIG_HOME`, `$XDG_DATA_HOME`, etc. See [`files/xdg-base-directory/`](files/xdg-base-directory/).

## Z

- **Zettelkasten** — Niklas Luhmann's slip-box note system; one idea per note, dense linking. See [`notes/zettelkasten-classic/`](notes/zettelkasten-classic/).

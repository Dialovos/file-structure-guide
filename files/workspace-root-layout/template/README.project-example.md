# Workspace

Everything I work on lives here. Each folder has one purpose.

| Folder | Contents |
|---|---|
| `projects/public/<name>/` | Code projects whose Git repository is public |
| `projects/private/<name>/` | Code projects whose repository is private or local-only |
| `business/<name>/` | Business work |
| `personal/` | Personal files and planning |
| `school/<course>/` | Coursework |
| `references/<topic>/` | Notes and research reused across projects |
| `tools/<tool>/` | Reusable utilities and shared environments |
| `inbox/` | Files waiting to be placed |
| `archive/YYYY-MM-DD-topic/` | Recovery material only |
| `.scratch/` | Temporary files; empty before finishing a task |

Do not create other top-level folders without a reason and a line in this table.

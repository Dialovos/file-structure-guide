# Workspace rules

Shared rules for every person and AI assistant working here.

## Where things go

See `README.md` for the map. New projects start in `projects/private/` unless they are meant to be public.

## Projects and Git

- Each project is its own Git repository; run Git inside it.
- No nested repositories, submodules, or copies of a project inside another.
- Use feature branches and pull requests. Ask before merging, force-pushing, or deleting branches.

## Privacy

- Keep secrets out of the workspace; real values belong in a keyring or a gitignored `.env`.
- Keep personal details out of anything that leaves this machine.

## Finishing a task

- Empty `.scratch/`, and remove temporary files.
- Verify duplicates by content and Git history before deleting anything.
